## Selected Projects

### Prime Supermarket POS (v2.2) — Hybrid Offline-First Retail System
An enterprise offline-first retail POS terminal and cloud synchronization backend built with .NET 8, WPF (MVVM), SQLite (WAL mode), ASP.NET Core Minimal APIs, EF Core 8, and PostgreSQL 16. Features sub-15ms local authentication (Argon2id + Windows DPAPI), automated SQLite hot backups, bidirectional Outbox cloud sync with Dead-Letter Queue, GS1 variable-measure EAN-13 barcode parsing, wholesale tier pricing, loyalty & store credit wallets, CSV import/export, and raw ESC/POS receipt spooling.
- **Repository:** [github.com/Zinolesky/pos-system](https://github.com/Zinolesky/pos-system)
